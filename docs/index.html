Every Last Grain data

Reference tables for Every Last Grain, the free desert-digging incremental game by Oliver Kuso, taken from the game's current demo build (Update 11). Raw JSON lives in the GitHub repository. For illustrated guides, tips and the update log, see the Every Last Grain fan guide.

Spoilers: this page names every buried item in the demo. Full-game content stays sealed until the full game is released.
