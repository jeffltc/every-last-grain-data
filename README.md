# Every Last Grain data

Reference data for **[Every Last Grain](https://oliver-kuso.itch.io/every-last-grain)**, the free desert-digging incremental game by Oliver Kuso. The files hold every find, tool, skill and area milestone, as JSON.

| File | Contents |
|---|---|
| [`finds.json`](finds.json) | All 14 Lot Edge finds (12 kinds) with rarity, value, in-game description and count, plus the 18 full-game kinds as the Collection shows them (rarity and value only) |
| [`equipment.json`](equipment.json) | The 6 demo tools with price and unlock condition, and the 4 shop upgrade lines |
| [`skills.json`](skills.json) | All 48 skills: branch, effect, prerequisites and Skill Point cost (58 SP in total) |
| [`areas.json`](areas.json) | Lot Edge milestones with rewards and messages; Dry Wash and Great Dune as listed in the Journal |
| [`achievements.json`](achievements.json) | All 11 achievements from the Records tab, with requirement and whether the demo can unlock it |

Values come from the game's current build (Update 19, checked 2026-11-27; unchanged since Update 8 except the 25% Lot Edge milestone, which now also gives Treasure Sense). They may change as the developer updates the game; pull requests with corrections are welcome.

**Spoilers:** these files name every buried item in the demo, including the special find. Full-game content stays sealed: the files only show it the way the game itself shows it (silhouettes with rarity and value). It will be added when the full game is released.

Browse it as tables: **[jeffltc.github.io/every-last-grain-data](https://jeffltc.github.io/every-last-grain-data/)**
